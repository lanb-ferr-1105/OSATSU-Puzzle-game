お札パズルゲーム

Python (Pygame) を使ってゼロから自作した、
ぷよぷよの要素を取り入れた進化・合成型のパズルゲームです。




  ゲームの特徴

お札の王様・1万円札をどんどん作って、スコアを稼ごう！

・「1000円札」を5枚くっつけると「5000円札」に、
・「5000円札」を2枚くっつけると「1万円」になって、画面から消え、スコアが加算されます。
・「2000円札」は、5枚くっつけないと、1万円になりません。


スコアが上がるにつれて落下スピードが徐々にアップし、スリリングな駆け引きが楽しめます。

ゲーム終了時、自己ベストスコアが、自動でファイル（`highscore.txt`）に保存されます。



操作方法

← / → キー：ブロックの左右移動

↓ キー： ソフトドロップ（加速落下）

SPACE キー：タイトル画面からのスタート / ゲームオーバー後のリトライ
